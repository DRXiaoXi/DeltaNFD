## 🛠️ 二、 首次启动与主页环境体检（必做三板斧）

首次打开 **三角帧不掉洲 (DeltaNFD)** 后，请先按提示**选择《三角洲行动》的游戏安装目录**。定位成功后，主页仪表盘会自动对当前电脑环境进行体检：
- **绿色正常**：代表该组件处于最佳状态，无需干预。
- **红色异常**：代表该组件正在严重拖累帧数或引发卡顿，请严格按以下三步将其恢复正常。

### 1. 着色器维护：解决编译掉帧与切换异常

《三角洲行动》在 DX11 模式下的着色器缓存管理机制非常脆弱。虽然 S11 赛季恢复了正常预热能力，但以下两种情况会被工具判定为**红色异常**：

1. **驱动版本问题引发的 `0KB` 残缺文件**：
   - S11 赛季 N 卡正常的着色器缓存应为 **`1 个 256MB 的 .nvph 文件` + `1 个 ≥256MB（通常为 512MB）的 .nvph 文件`**。
   - 若使用了存在缺陷的驱动版本，会少一个 256MB 文件并变成 **`0KB` 的 `.nvph` 文件**，帧数显著低于正常水平。
2. **多 `GameVer` 文件夹切换异常（N 卡 / A 卡 / I 卡均受影响）**：
   - 当你更新显卡驱动或修改显卡型号后，游戏会新建一个 `GameVer` 文件夹另起炉灶。但由于官方切换机制存在 Bug，一旦没切对就会导致掉帧，因此存在多个 `GameVer` 文件夹时工具也会判定为异常。

#### 📊 N 卡驱动版本红黑榜与推荐表

| 驱动分类 | 具体版本号要求 | 实测说明 |
| :--- | :--- | :--- |
| ✅ **基础准入要求** | 驱动版本必须 **`≥ 572.83`** | 低于此版本无法保证当前赛季特性正常运作 |
| ❌ **绝对避坑黑名单** | **禁止使用 `591` 系、`610` 系、`616` 系及 `620.14`** | 无法完整编译着色器，会出现 `0KB` `.nvph` 残缺文件并严重掉帧 |
| 🏆 **RTX 30 系及以下推荐** | 强烈推荐 **`576.88`** | 原作者针对 30 系及更早 N 卡实测最稳版本 |
| 🏆 **RTX 40 系 / 50 系推荐** | 强烈推荐 **`596.49`** | 原作者针对 40 系 / 50 系新架构实测最稳版本 |

#### 🔄 清理着色器后的「标准三步预热法」（极重要！）

更换好推荐驱动（或完成显卡伪装）后，在工具「着色器」页面点击 **「清理着色器」**，然后**必须严格按以下三步重新预热**：

1. **第一步：游戏大厅静止预热（看 CPU 占用率）**
   启动游戏进入大厅（若未自动开始预热，请在游戏「画质设置」中点击「重新预热」并重启游戏）。进入大厅后**切勿立刻开始匹配！先在大厅静止等待几分钟**。
   > 💡 **如何判断大厅预热完成？**
   > 《三角洲行动》将一部分预热步骤转移到了游戏大厅。请打开 Windows **任务管理器**观察 CPU 占用率：**CPU 占用率高代表正在后台编译预热，当 CPU 占用率逐步回落到一个平稳的低值时，即代表大厅预热完成。**
2. **第二步：靶场跑图二次预热**
   大厅 CPU 占用平稳后，进入 **「靶场」** 跑动一圈，触发并完成第二部分着色器文件的预热。
3. **第三步：重启游戏满血生效**
   靶场跑完后，**彻底退出游戏，再重新启动进入游戏**，此时着色器缓存即处于最完美的满帧状态！

### 2. ACE 反作弊组件清理：解决局内外周期性顿卡

- **异常原因**：经排查发现，当系统内 `ACE-CORE` / `ACE-Base` 系列反作弊驱动累积达到 **2 个或以上文件**时，极易引发对局内外莫名其妙的周期性微卡顿与掉帧。
- **标准处理步骤**：
  1. 进入工具「ACE」页面，点击 **「一键清理 ACE」** 清除冗余驱动残留。
  2. 打开**游戏官方启动器**或 **WeGame**，执行一次 **「游戏修复」**。
  3. 启动游戏时会弹出 **「ACE 预启动」安装弹窗**，请确保你的系统或安全软件没有限制该弹窗运行，正常点击安装即可。
  > 💡 **进阶提示**：如果你的电脑环境特殊，实测不需要安装 ACE 预启动就能正常进入对局，那么强烈建议你**不要安装**。

### 3. 运行库重装与防篡改守护：解决静默更新掉帧

- **异常原因**：由头号测试员 `@14代耐电王` 协助在高性能平台上进行同点位对比测试证实：《三角洲行动》会在后台**静默安装最新版 v14 运行库**，直接导致游戏帧数大幅下跌（实测从 `351 FPS` 跌至 `302 FPS`）。
- **不同 C++ 运行库（2015–2022）版本实测特性**：
  - 🏆 **`14.42` 版本（工具内置默认集成）**：**帧数最高**（实测 `351 FPS`），操作延迟略高一丝，综合体验最佳。
  - ⚡ **`14.40` 版本**：帧数适中（实测 `334 FPS`），但**操作延迟最低**。

::: danger 🚨 点击「重装运行库」前的防崩溃警告（必读！）
点击工具内的 **「重装运行库」** 后，程序会先**卸载当前系统内所有的 VC++ 运行库**，再干净安装工具内置的 `14.42` 版本。
**在卸载重装过程中，所有依赖 C++ 运行库的软件（包括微信、浏览器、游戏平台、录制软件等）都会直接崩溃退出！因此，重装运行库前请务必保存工作并关闭其他正在运行的软件！**
:::

#### 🛡️ 开启运行库防护模式（防止游戏再次静默覆盖）
重装完成后，建议在页面内开启 **「运行库防护模式」**（基于 IFEO 映像劫持拦截）：
- **基础防护（v14）**（推荐）：仅精准拦截 `v14` 版本的 `.exe` 运行库安装包。
- **完全防护**：拦截系统内所有的 C++ 运行库安装行为。
  > ⚠️ **完全防护特别提醒**：开启「完全防护」后，如果你后续安装**显卡驱动、WeGame/Steam 新游戏或其他办公软件**，它们自带的 C++ 运行库安装程序也会被一并拦截报错。遇到安装失败时，只需回到本工具**关闭防护并点击「清理拦截」**，安装完软件后再重新打开防护即可。

## 🚀 三、 六大进阶调优模块实操指南

完成上述三板斧消除主页红字后，你可以根据自身硬件配置，按需启用以下进阶模块将帧数推向电脑的稳定极限。

### 1. 系统优化：UP 推荐分类与虚拟内存固定

本模块参照了 BoosterX 的底层优化项目进行本土化重构。**如果你使用的是精简版系统，这里绝大多数项目无需再调；如果是原版 Windows 10/11，强烈建议普通玩家只优先执行「UP 推荐」这一栏！**

#### ✅ 「UP 推荐」核心勾选项说明（按需执行）
1. **禁用自动加密（BitLocker）**：**请先检查你的「自动加密」是否为开启状态，如果是开着的请直接关掉！** 避免后台磁盘加密严重拖慢游戏加载与读写。
2. **暂停 100 年更新**：防止 Windows Update 在打游戏时后台偷跑 CPU、占用网速或强行替换显卡驱动。
3. **禁用遥测 & 禁用快速启动**：减少系统后台遥测上报，消除“快速启动”长期不彻底关机导致的内核状态堆积。
4. **禁用 VBS（基于虚拟化的安全性） & 关闭预读取（Prefetch）**：释放被虚拟化占用的硬件性能。
5. **关闭内存压缩 & 禁用合并分页**：
   > ⚠️ **内存容量门槛**：仅当你的电脑 **物理内存 > 24GB（如 32GB / 64GB）** 时，才建议关闭内存压缩和分页合并；16GB 及以下内存请保持默认开启。
6. **关闭鼠标加速 & Win11 24H2 区域内存优化**：改善鼠标跟手度与新版系统内存调度。

*(注：除「UP 推荐」外的其他底层选项，建议具备一定 Windows 系统知识的高级玩家再行操作。)*

#### 💾 虚拟内存（页面文件）修改建议
- **为什么要改？** Windows 默认的「自动管理虚拟内存」初始最小值通常设得较小。当《三角洲行动》高负载运行导致虚拟内存动态扩容时，极易引发明显的画面顿卡。
- **推荐做法**：在工具内直接**固定虚拟内存的最小值与最大值**（避免系统在游戏过程中动态扩容），即可有效消除因页面文件增长引发的额外卡顿。

### 2. 显卡伪装：解锁隐藏最低画质与网吧免重启模式

- **功能原理**：通过修改注册表中游戏识别到的显卡型号名称，将显卡伪装成特定的低端型号（如 `GTX 1050 Ti` 等），从而激活《三角洲行动》内部隐藏的极低画质预设，大幅降低渲染压力、提升帧数。
- **家用机标准流程**：
  `选择伪装型号并应用` → `前往「着色器」页删除着色器缓存` → `进游戏大厅静止等待预热` → `进靶场跑图预热` → `重启游戏生效`。
- **🏢 网吧玩家专属：「临时模式 + 立即重启显卡」**
  针对网吧机器重启即还原的限制，勾选 **「临时模式」** 并点击 **「立即重载显卡（不重启）」**，工具会通过底层禁用并重新启用显卡设备，实现**免重启电脑直接切换显卡型号**！
  > ⚠️ **注意**：重载显卡瞬间屏幕会短暂黑屏闪烁 1~3 秒，**切勿在游戏或 3D 程序正在运行时点击**，否则会导致正在运行的游戏直接崩溃。

### 3. N 卡设置：DLSS 超分模型与烟雾马赛克修复

本页面通过直连 NVIDIA 底层驱动接口（NvAPI）修改游戏配置，无需安装笨重的第三方 Inspector 工具：

| 设置项 | 原作者实测推荐档位 | 作用与性能影响说明 |
| :--- | :--- | :--- |
| **超分模型修改 (DLSS)** | • **`K` 模型**：**最均衡（综合首选）**<br>• **`F` 模型**：性能损耗最低（低配首选）<br>• **`L` 模型**：画面最清晰，但性能损耗较大<br>*(备选：`M` 模型)* | 显著改善游戏开启 DLSS 后的远景与动态清晰度，告别原版糊屏感 |
| **抗锯齿透明度** | • DLSS **质量档** → 开 **`×2`**<br>• DLSS **平衡档** → 开 **`×4`**<br>• DLSS **性能档** → 开 **`×8`** | **彻底解决烟雾、火焰糊成一坨马赛克的核心设置！** 请严格按你在游戏内开启的 DLSS 档位对应选择 |
| **CUDA 显存回退策略** | 显存 **≥ 8GB** 推荐开启 **「偏好不回退」** | 防止显存接近满载时回退调用系统内存，有效减少激战时的掉帧现象 |

### 4. 帧格：运行时持续稳帧与 DWM 自愈

「帧格」是本工具的重头戏，开启后会在游戏运行期间持续改善帧率表现与系统响应（可在主页开启「一键帧格模式」联动，在「帧格」页独立控制各子开关）：

1. **🩺 降低 DWM CPU 占用（Intel 显卡玩家 100% 必开）**：
   - **如何判断自己是否中招？** 在启动游戏前打开任务管理器，观察 `桌面窗口管理器 (dwm.exe)` 的 CPU 占用；如果**启动游戏前 `dwm` 占用极低，但游戏运行后 `dwm` 的 CPU 占用大幅飙升**，且手动结束 `dwm` 进程重开后占用又恢复正常，就说明你遭遇了此 Bug（目前实测 **Intel 显卡玩家 100% 遭遇此问题**）。
   - **作用**：开启该功能后，工具会在目标游戏启动后自动干预，将 `dwm.exe` 的异常 CPU 占用压回正常水平。
2. **🔒 电源计划锁定**：将系统电源计划强制锁定为你指定的计划（30 秒巡检一次），彻底防止被游戏或后台软件偷偷改回平衡/省电计划。
3. **⚡ 加速系统响应速度 & 前台响应加速**：开启高精度系统定时器并禁用游戏进程 EcoQoS，将系统更多计算资源优先分配给前台游戏窗口。
4. **🔌 降低省电延迟**：抑制核心停放与外设（网卡 / USB / PCIe）省电休眠，消除省电唤醒瞬间造成的额外输入延迟与网络延迟。

### 5. CPU 实验室：无省电电源计划与 AMD 双 CCD 调度

#### 🖥️ 1. 无省电电源计划（台式机推荐）
- 点击即可一键导入定制的 **「无省电电源计划」**，关闭处理器底层省电休眠状态，把 CPU 性能激发到最大限度。
- ⚠️ **笔记本玩家注意**：笔记本电脑受限于散热模组与功耗墙，导入前请先确认散热良好。

#### 🔴 2. AMD 处理器专属调度（单 CCD / 双 CCD）
- **单 CCD 处理器（如 7800X3D / 9800X3D / 5700X3D 等）**：
  支持开启 **「单 CCD 调度（排除 CPU 0）」**，取消游戏对 `CPU 0`（系统中断最密集核心）的占用，提升 `1% Low` 帧稳定性。
- **双 CCD 处理器（如 R9 7900X / 7950X / 7950X3D / 7940HX / 8945HX 等）**：
  - **核心原理**：通过底层 `CPU Sets` 软硬约束结合，**将系统内其他所有后台进程全部驱赶到另一个 CCD 上，让《三角洲行动》独占整颗 CCD 的全部计算核心与三级缓存（L3 Cache）**——既最大化利用整颗处理器的多核性能，又彻底规避了跨 CCD 通信延迟（IF 总线延迟）带来的严重掉帧！

::: warning ⚠️ AMD 双 CCD 玩家必看：不同游戏模式的开闭法则！
根据原作者在 R9 7940HX 游戏本上的实机对比测试，不同玩法模式对双 CCD 调度的反馈截然不同：
- ✅ **全面战场 & 烽火地带（摸金）**：**强烈建议开启「双 CCD 专属调度」**！实测全面战场与总裁激战下的帧数上限、帧时间平滑度远超单 CCD 或默认混合调度状态。
- ❌ **黑潮爆破模式**：**强烈建议关闭「双 CCD 专属调度」**！实测官方在「黑潮爆破」中已单独优化了 CPU 调度；开启双 CCD 反而会因为两颗 CCD 同时高负载发热导致更卡，关闭后 CPU 温度更低、画面极其丝滑。
:::

#### 🔵 3. Intel 处理器调度
- 目前提供 **「自由调度」** 模式，支持高级玩家手动配置核心亲和性（如有更好的 Intel 大小核专属调度建议，欢迎加群与原作者交流）。

### 6. 进程管理、拓展插件与全局设置

1. **🧹 后台内存压力回收（原帧格「内存清理」升级版）**：
   - **入口位置**：`进程管理` → `后台管理` → `后台内存回收`。
   - **适用人群**：专为**一玩三角洲就爆内存的 16GB 内存玩家**准备，支持按内存压力自动或手动回收后台进程工作集（不会强行结束后台进程）。
   - ⚠️ **注意**：清理内存工作集可能引起后续换页开销并在一定程度上降低性能，**内存充足（32GB+）不爆内存的玩家请酌情开启或保持关闭**。
2. **🎮 「不玩三角洲辣」跨游戏调度模式**：
   - **入口位置**：`设置` → `不玩三角洲辣`。
   - **功能说明**：如果你哪天想玩其他游戏，可以打开此模式并指定其他游戏的主进程（`.exe`），即可将本工具的 **「帧格」、「进程管理」与「CPU 调度器」** 无缝转移到其他游戏上生效！（注：着色器、ACE 与运行库三大模块仍仅针对《三角洲行动》）。
3. **🔌 拓展插件（`.dnfdplugin`）**：
   - 预留的模块化扩展接口，支持导入官方或社区开发的 `.dnfdplugin` 插件包（如弱网优化、硬件报告等），支持逐项权限授权、查看运行历史与备份回滚。技术规范详见 **[插件开发指南](/guide/plugin-dev)**。
4. **⚙️ 外观、托盘与自动更新**：
   - 支持开关自定义背景图、切换深浅主题色、开机自启动与最小化到系统托盘运行。
   - 内置**自动更新**功能（当前更新源位于 GitHub，后续计划增设国内高速更新源）。

## 🛡️ 四、 备份还原、异常处理与问题反馈

本工具坚持 **「纯系统级合法调优 · 不修改游戏内存与客户端文件」** 原则，所有涉及注册表、系统服务、电源计划与驱动配置的修改均配有安全备份与恢复机制：

1. **如何回滚设置？**
   - 如果你在尝试某项高级系统优化、显卡伪装或插件后感觉帧数下降或系统异常，可直接在对应功能页或恢复入口执行 **「单项恢复」** 或 **「一键恢复备份」**。
   - 若遇到极端断电或后端超时，下次启动软件时会自动弹出 **「未确认操作核对」** 提示，请按引导一键还原残留状态。
2. **遇到 Bug 或优化无效如何反馈？**
   - 目前工具处于公开测试与持续迭代阶段。如遇软件 Bug 或特定配置下帧数下降，请前往 **[📺 原作者 B 站视频 (BV1AWHW6hEBE)](https://www.bilibili.com/video/BV1AWHW6hEBE/)** 的**评论区置顶动态**加入粉丝反馈群，或前往 **[GitHub Issues](https://github.com/DRXiaoXi/DeltaNFD/issues)** 提交反馈。
