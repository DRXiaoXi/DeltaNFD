# Alpha0.935 / 0.9350

本地 Alpha 构建，尚未上传或加入更新通道。Win10 1809+ x64 由玩家自备原版 DPC Latency Checker 1.4.0 EXE：可保存基础1.0000ms，也可运行与Win11相同的算法1、2扫描最优值。算法方式由DPC保持1ms基底，额外工具进程申请扫描值；核对候选读数、独立等待与联合持有，释放成功后才保存，随帧格同时开启/释放。Win11 保持原路径。

帧格只在当前准备与检测保存完成后显示钟摆联动项。Win11开启帧格后持有对应精度并忽略三角洲自身请求；Win10同时保持DPC在后台，基础方式持有1ms，算法方式持有保存的目标。独立忽略开关收进联动，不需要另开；旧偏好保留存储但不能绕过准备。Win10必须先在独立子进程核验策略能力，两系统均保留时钟可达性、目标回读和写前记录；停止时先恢复游戏策略再释放请求。未保证所有Win10版本或游戏环境可用。

“不玩三角洲辣”模式下，帧格CPU/IO/内存优先级和钟摆精度忽略现已跟随所选EXE，按完整路径、PID、启动时间和目标代次核验；同名其他目录及同时运行的三角洲不会纳入。旧三角洲记录仍可恢复，自定义游戏的新记录绑定当时核验的映像路径，切换目标后也能核对恢复；遇到权限或回读拒绝会保留责任，不保证所有游戏允许修改。

新安装包不附带 DPC EXE/SYS 或旧自研测试驱动，不自动下载、复制或提取原件。原版 DPC 自行加载旧驱动，存在 CVE-2025-51619；有效签名不保证反作弊兼容。工具不修改 TESTSIGNING、证书或启动安全设置，也不自动续办旧准备。使用与旧环境恢复见 `docs/Win10-DPC.md`。

Win10默认在核验成功后持续隐藏自有DPC主窗口，可在钟摆页取消隐藏；启动阶段可能短暂显示，错误弹窗保留。关闭帧格或退出工具仍按原记录正常关闭并核对释放，不改变算法1/2和基础1ms方式。

包含此前本地的着色器识别、自启动管理和窗口布局修复。Win10基础1ms只核对进程、服务及系统数值；算法方式会测量Sleep并施加CPU负载。DPC自身授予值仍不暴露，算法显示的授予值来自额外请求；检测不能证明游戏收益。以下保留此前已发布版本说明。

## 此前发布：Beta0.932-RC2 / 0.9321

公测版可选更新，自建公测、内测双通道及 GitHub 同步安装包和对应源码。

- 修复本地发布缺少 WinUI 启动资源造成的黑屏或启动失败，构建时校验资源完整性。
- 改进 Windows 注销时 CPU/帧格的收尾与还原；未完成仍保留核对保护。
- 修复 CPU 断连记录被只读检测覆盖的问题，完善证据落盘、子进程身份核对，并为损坏运行库外层记录、失效旧电源计划备份提供显式处理入口。
- 新增本地 MCP Agent 接入，正常启动默认开启；Agent 写入仍需要软件内确认，并保留管理员、游戏运行、备份和核对限制。
- 帧格 CPU 优先级默认改为“高于正常”，IO 默认改为“正常”，保留已有显式设置。
- 检测到内部版本更高的新 Beta 时，左上角版本号后提示“过时版本”。
- 包含 RC1 的预读取复检、NVIDIA 防闪屏性重置枚举修复与未知后端异常处理指引。

钟摆计划和忽略三角洲精度请求继续隐藏，默认不提升游戏优先级。不含退役卡顿检测、运行库研究策略或私有反馈。更新不强制，不自动重启。

本次验证以隔离夹具、模拟写入及 Win11 只读检查为主，未验证 Win10、跨 UAC、真实游戏画面或系统优化实效。历史断连的原始会话不全，不能认定所有断连根因均已解决。

源码构建使用 .NET SDK 8.0.425、Python 3.11+，安装器需 Inno Setup 6。先运行 `python tools/prepare-source-assets.py` 校验并恢复固定厂商依赖，再运行 `installer/publish-selfcontained.ps1`，以 `installer/DeltaNFD.iss` 打包。详见 SOURCE_BUILD.md；Agent 接入见 docs/MCP本地Agent接入.md。
