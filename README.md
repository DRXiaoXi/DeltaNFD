## Beta0.93-RC2 · 公测更新

显示版本 Beta0.93-RC2，内部版本 0.9302。

- 修复运行库页切换后继续使用旧页面会话、无法切换防护的问题。
- 游戏状态后端不可用时使用独立只读进程检测；保留异常记录与执行限制，不重放帧格操作。
- 核验三种内存回收模式的持续高压触发、双开关与暂停条件。
- C++ 14.x 安装与修复统一使用微软 14.44 原包；移除 14.42 安装资源，已安装的 14.42 标为已过时。
- 强制替换并入权限/属主备份、临时接管及恢复能力，保留当前实现。
- 修复系统优化 HAGS 长状态文字布局与刷新状态后误显示“准备还原”。
- 更新使用教程，解释显卡伪装、运行库、缓存清理、内存回收、CPU 调度和帧格选项的用途与推荐场景。
- 保留正常模式/安全模式分阶段修复及已有游戏、恢复限制。

不包含卡顿检测、着色器研究或独立预热客户端。强制替换独立验收指出的只读文件回滚、排程状态及完整 ACL 核对问题尚未修复；本次按现有实现发布。验证以隔离/模拟及只读检查为主，未进行真实系统 DLL 替换或重启验收。

**普通用户下载：** 在 Assets 中选择 **DeltaNFD_Setup_0.9302_x64.exe**。
源码为 DeltaNFD_Source_0.9302.zip；更新分块仅供软件自动使用，无需手动下载。

Windows x64 / .NET 8。先运行 `python tools/prepare-source-assets.py` 获取并核验固定二进制构建资源，再运行 `installer/make-installer.cmd`。
构建资源固定为 0.9200 原始输入和 0.9299 官方 14.44 输入；不包含 14.42 安装媒体。保留六个维护后端与历史恢复记录兼容身份。
