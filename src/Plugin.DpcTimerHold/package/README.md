# DPC 计时器常驻（io.github.drxiaoxi.dpc-timer-hold）

面向「三角帧不掉洲 / Delta NFD」的 Windows 10 研究插件，规范 1.0。它把外部视频里的「4.1 方法」——**保持原版 DPC Latency Checker 1.4.0 运行**——做成插件操作：由玩家自备的原版 DPC 自行加载其签名驱动并持有 1.0000ms 的系统计时器精度请求，本插件只负责**启动、核验与释放**。

本插件**不包含、不提取、不复制、不直接加载任何驱动**，也不下载原版 DPC；玩家必须自己提供原版文件，插件只按固定 SHA256 核对身份。

## 作者

DRXiaoXi（三角帧不掉洲作者）。

## 支持系统

- **Windows 10 x64，1809（build 17763）至 21H2（build 21999）**。Win11 已有宿主内置钟摆路径，本插件在 Win11 上直接拒绝启动。
- 宿主必须以管理员身份运行（宿主清单为 `requireAdministrator`，插件后端继承该令牌）。
- 后端自包含发布，不要求用户另外安装 .NET 运行时。
- 启动合同为 `--dnfd-pipe <name> --dnfd-session <非零 UUID> --dnfd-host-pid <宿主 PID>`：后端连接宿主随机命名管道，核对管道服务端与宿主身份并回显握手 nonce，握手最长 10 秒；会话不匹配立即断开退出。该身份核对是协议一致性检查，**不是权限沙箱，也不提供对恶意管理员的防护保证**。

## 前置条件：玩家自备原版 DPC 1.4.0

本插件不附带 DPC 文件（原厂再分发未获书面授权，且原厂页面已停止提供该工具）。请使用你自己合法持有的原版 `DPCLatencyChecker_V1.4.exe`：

| 项目 | 值 |
| --- | --- |
| 字节数 | 306928 |
| SHA256 | `00a7c7b88877bf59dbaa70de734fcd3f287f1eb92caff4571a4c8e67a5dc0aca` |

文件路径有两种提供方式：

1. 在插件页「原版 DPC 1.4.0 EXE 完整路径」里填写完整路径；或
2. 把文件放到插件数据目录的 `input\DPCLatencyChecker_V1.4.exe`（留空路径时自动读取）。

身份不匹配（字节数或 SHA256 不同）会被拒绝，插件不会运行被替换或修改过的程序。插件在核验后以只读共享句柄保持文件锁定直到常驻确认，缩小「核验后被替换」的窗口；但这不是通用的防篡改保证。

## 功能

插件页面提供「检查环境与状态」（`probe`，只读）和「启动 DPC 常驻」（`start`，修改型、可恢复）两个按钮，打开插件页不会自动启动后端。

- **probe**：只读报告系统版本、是否管理员、Secure Boot 状态、原版文件身份、常驻记录、`dpclat_driver` 服务状态与系统当前计时器分辨率读数。不启动任何程序、不改动服务。
- **start**：校验环境与文件身份 → 启动玩家自备的原版 DPC → 等待并核验 `dpclat_driver` 处于 RUNNING 且系统分辨率读数 ≤ 1.0000ms → 把进程身份、服务映像与读数写入插件数据目录的常驻记录。DPC 窗口保持运行以维持请求。
- **释放**：在宿主「插件管理页 → 恢复备份…」执行 `restore`。插件会正常关闭**本次启动的** DPC 进程，核验 DPC 自行删除其服务；若 DPC 异常退出留下归属可核验的遗留服务，才在类型/启动类型/映像路径全部匹配记录时停止并删除该服务。归属不明时**不做任何改动**并保留记录。

也可以直接关闭 DPC 窗口，然后点「恢复备份…」清除记录（插件检测到进程已退出会按已释放处理）。

### 为什么需要「恢复备份」来释放

宿主插件合同把修改型操作统一建模为「执行意图 + 待恢复记录」：任何 `mutating:true` 操作返回后都会留下待恢复记录，并在恢复前阻止新的 invoke。这是宿主的安全模型，不是本插件的额外限制。因此本插件的流程是：**启动常驻 → 需要释放时点「恢复备份…」**。恢复是幂等的，失败会保留记录可重试。

### 与「三角帧不掉洲」钟摆的关系

本插件不修改宿主、不读取帧格状态、不注入游戏。它是独立的研究/对照工具：在 Win10 上提供一条**使用第三方已签名驱动**的内核计时器请求路径，用来对照宿主自研测试签名驱动路径（0.5000ms）与用户态路径。插件持有的是 DPC 的固定 **1.0000ms** 请求，不是 0.5000ms；DPC GUI 固定提交 1000 微秒，本插件不直接驱动其设备接口，也不改变该值。

## 风险

请在使用前完整阅读。以下是本插件的真实边界，宿主无法替用户确认：

- **已知内核漏洞**：DPC 1.4.0 存在 [CVE-2025-51619](https://nvd.nist.gov/vuln/detail/CVE-2025-51619)，涉及本地低权限用户可触发系统蓝屏的驱动缺陷。加载该驱动会扩大本机攻击面；有效签名不修复漏洞，也不代表反作弊允许加载。
- **驱动来源与签名**：驱动内嵌在玩家自备的原版 EXE 中，由原版 DPC 按其自身流程安装；本插件不改变签名、不关闭 Secure Boot、不开启测试签名、不修改 BCD/证书/启动配置。该驱动为 2010 年前后签发的旧式签名，在开启 Secure Boot 的部分 Win10 机器上可能无法加载；插件会报告 Secure Boot 状态，但不会尝试绕过。
- **管理员后端**：后端以管理员身份运行。能力声明、确认弹窗、协议校验和独立进程都不是权限沙箱，**不能限制本插件的实际行为**。
- **反作弊**：不保证任何反作弊兼容。加载内核驱动可能被游戏或反作弊视为风险行为；不要把它宣传为不存在封号风险或获得反作弊放行。
- **效果未验证**：插件只确认「服务 RUNNING + 系统分辨率读数 ≤ 1ms」。这不等于跨进程 `Sleep(1)`、帧时间、输入延迟或游戏收益已改善；历史 Win10 客体日志显示分辨率读数变化与实际等待可能脱节。本插件不运行 Sleep 测量、CPU 压力或游戏测试。
- **宿主退出不会自动关闭 DPC**：`stop` 只停止插件后端，不隐式释放外部 DPC。关闭宿主后 DPC 窗口会继续运行；请用「恢复备份…」或直接关闭 DPC 窗口释放。若后端被强杀或机器异常重启，插件数据目录中的常驻记录会保留，下次可点「恢复备份…」清理。
- **不结束非本插件启动的进程**：只正常关闭本次记录且身份（PID + 启动时间 + 映像路径）复核通过的 DPC；不按进程名强杀。
- 本插件不声明持续运行（`continuous`）与脱机自主运行（`offlineAutonomous`），不安装服务、计划任务或自启动项。

## 与插件规范第 1 节的关系

规范第 1 节写明插件协议「禁止……安装内核驱动」。本插件**自身不安装、不加载内核驱动，也不包含任何驱动文件**；驱动由玩家自备的原版 DPC 安装。是否把「启动会安装驱动的第三方程序」视为规避该条款，属于项目方的判断。本包标注为**本地研究插件，不随产品分发**，也不代表项目对第三方驱动再分发或反作弊兼容的立场。

## 直接改写范围

本插件自身**不写**注册表、BCD、证书、启动配置、驱动目录或游戏文件。运行 `start` 时会发生：

1. 启动玩家自备的原版 DPC（原版程序自行创建并按需启动 `dpclat_driver` 内核服务，驱动文件位于 `%SystemRoot%\System32\drivers\dpclat.sys`，由原版程序退出时删除）；
2. 在插件数据目录写入常驻记录与日志（见下）；
3. `restore` 时正常关闭本次启动的 DPC，并在归属可核验时清理其遗留服务。

## 备份位置与恢复方法

**记录位置**（插件数据目录，宿主不会清理）：

```text
%LOCALAPPDATA%\Delta NFD\PluginData\io.github.drxiaoxi.dpc-timer-hold\
    hold-state.json     常驻记录：阶段、backupId、DPC PID/启动时间/路径、服务映像、请求值与读数
```

**恢复方法**，任选其一：

1. 宿主「插件管理页 → 恢复备份…」——推荐方式；插件执行同一套释放逻辑并逐项报告。
2. 直接关闭 DPC 窗口，再点「恢复备份…」清除记录。
3. 手动检查：确认 DPC 已退出、`dpclat_driver` 服务不存在后，删除 `hold-state.json`。

恢复是幂等的。若检测到服务归属与记录不符，插件报告 `RESTORE_FAILED` 并保留记录，不删除服务、不冒充成功。

## 脱机限制

不支持脱机移交。本插件未声明 `offlineAutonomous`，即使宿主开启「允许插件在脱机模式下运行」也不会被移交；宿主退出后本插件没有常驻后端进程（但玩家自备的 DPC 进程不受插件管理，见上）。

## 权限用途

| 权限 | 实际用途 |
| --- | --- |
| `process.launch` | 启动玩家在插件页指定、且 SHA256 匹配原版 1.4.0 的 DPC EXE；不下载、不附带该程序 |
| `system.modify` | 原版 DPC 自行创建/启动 `dpclat_driver` 内核服务并持有系统计时器请求；本插件只启动/正常关闭该进程并只读核验服务与分辨率 |
