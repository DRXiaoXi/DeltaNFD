# 硬件报告示例（org.example.hardware-report）

拓展插件规范 1.0 的最小只读参考实现。

## 作者

Example Author

## 支持系统

Windows 10/11 x64（需要 .NET 8 运行时或自包含发布）。

开发构建依赖 .NET 8；分发插件包时必须自包含发布，将 publish 目录完整放入 backend，不要求玩家安装开发运行时。启动合同为 `--dnfd-pipe <name> --dnfd-session <非零 UUID> --dnfd-host-pid <宿主 PID>`；后端核对管道服务端及会话，握手读取最多 10 秒。该身份核对不提供管理员权限沙箱或对恶意管理员的防护保证。

## 功能

收集系统版本、逻辑处理器数量等只读摘要，在插件页面展示。勾选“详细信息”会附加运行环境描述。

## 风险

- 本示例只读取系统信息，不修改任何系统设置、注册表、文件或游戏进程。
- 后端以管理员身份运行；即使是只读插件，宿主也无法强制限制其行为。
- 本插件不声明持续运行（continuous）或脱机自主运行（offlineAutonomous）能力。

## 直接改写范围

无。`report` 操作为 `mutating: false`，不产生任何系统改动，因此没有备份。

## 备份位置与恢复方法

不适用（无修改操作）。

## 脱机限制

不支持脱机移交。宿主启用“允许插件在脱机模式下运行”后本插件仍不会被移交（未声明 offlineAutonomous），脱机模式下宿主退出后本插件后端不会运行。
