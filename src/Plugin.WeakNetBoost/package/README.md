# 弱网加速（io.github.drxiaoxi.weaknet-boost）

面向「三角帧不掉洲 / Delta NFD」的弱网加速拓展插件，规范 1.0。开关打开后，本工具的**检查更新**与**安装包下载**改走 [gh-proxy](https://gh-proxy.com/) 加速节点，缓解国内直连 `api.github.com` / `raw.githubusercontent.com` / `github.com` 超时与慢速问题。

## 作者

DRXiaoXi（三角帧不掉洲作者）。

## 支持系统

Windows 10/11 x64。后端自包含发布，不要求用户另外安装 .NET 运行时。

启动合同为 `--dnfd-pipe <name> --dnfd-session <非零 UUID> --dnfd-host-pid <宿主 PID>`：后端连接宿主随机命名管道，核对管道服务端与宿主身份并回显握手 nonce，握手最长 10 秒；会话不匹配立即断开退出。该身份核对是协议一致性检查，**不是权限沙箱，也不提供对恶意管理员的防护保证**。

## 功能

插件页面提供「启用弱网加速」开关和两个按钮：

- **应用开关设置**（`apply`，修改型、可恢复）：按开关状态改写成加速配置，或还原成开启前的原样。
- **检查加速状态**（`probe`，只读）：读取当前生效的更新源、加速节点连通性与延迟、加速清单里的版本号和实际下载地址，并在加速清单落后于 GitHub 线上最新版时给出提示。

`probe` 在 `ui.json` 里由「检查加速状态」按钮触发，**打开插件页不会自动联网或启动后端**。

## 侧栏入口

本包为 manifest schema 2，声明一个侧栏入口 `navigation: { "label": "弱网加速", "icon": "activity", "pageId": "main" }`，由宿主在「拓展插件」节点下生成子菜单。入口只是导航声明：打开它只渲染本页 `ui.json`，不会启动后端、重连、移交或恢复。未授权、已停用或宿主版本不兼容时入口仍可进入宿主的管理详情，但执行控件被禁用。

## 风险

请在使用前完整阅读。以下是本插件的真实边界，宿主无法替用户确认：

- 后端以管理员身份运行。能力声明、确认弹窗、协议校验和独立进程都不是权限沙箱，**不能限制本插件的实际行为**。
- 开启后，本工具的更新检查与安装包下载会经过第三方网关 **gh-proxy.com / gh-proxy.org**。该服务与本工具作者无关，属于第三方公共服务，其可用性、稳定性与长期存续不由本工具保证，也无法保证它不记录访问元数据。
- 加速配置文件（更新清单）本身**没有签名**。安装包仍由宿主强制校验 SHA256 与文件大小，加速节点无法用被替换的安装包通过校验；但被篡改的清单可以改变「从哪里下载」与「显示什么版本号」。
- 加速清单是一份放在仓库里的静态文件。如果发布方更新了版本却没有重新生成它，插件页的 `probe` 会提示「加速清单落后」，但**宿主自身的检查流程可能因此看不到更新的版本**——这一条靠发布方维护，无法由插件自动修复。
- 加速只影响本工具的 GitHub 更新链路，**不加速游戏内网络**，也不改变游戏延迟、丢包或反作弊状态。
- 本插件不声明持续运行（`continuous`）与脱机自主运行（`offlineAutonomous`），不安装服务、计划任务或自启动项。

## 直接改写范围

只改写**一个文件**：

```text
%APPDATA%\Delta NFD\update-source.json
```

（即宿主文档里给「加国内镜像」预留的用户级更新源配置，优先级高于程序目录里的 `Assets\UpdateConfig.json`，且升级安装不会覆盖它。）

改写内容仅限：`manifestUrls`、`allowedHosts`、`checkTimeoutSeconds`、`downloadTimeoutMinutes`、`releasePageUrl` 等更新源字段，并写入一段说明注释。本插件**不改动**程序安装目录、注册表、系统服务、游戏进程或其他任何文件。

改写是原子的：先写同目录临时文件，再 `File.Move(overwrite: true)` 替换。若目标路径或其任一父目录是重解析点（符号链接 / 目录联接），插件拒绝改写并报错，避免写到别处。

## 备份位置与恢复方法

**备份位置**（插件数据目录，宿主不会清理）：

```text
%LOCALAPPDATA%\Delta NFD\PluginData\io.github.drxiaoxi.weaknet-boost\
    update-source.backup.bin      开启前的原文件完整字节
    weaknet-boost.state.json      状态：是否已开启、原值哈希、最后写入哈希、backupId 与时间
```

首次开启时保存原文件的**完整字节**（不是解析后的字段），所以还原是字节级还原，不会丢注释或格式。如果开启前该文件根本不存在，插件记录「原值不存在」，关闭时删除自己写入的文件而不是留下一个空配置。

**恢复方法**，任选其一：

1. 在插件页面取消勾选「启用弱网加速」并点「应用开关设置」——插件按备份还原（这是推荐方式）。
2. 在宿主的插件管理页点「恢复」——宿主向本后端发送 `restore(backupIds)`，本插件执行同一套还原逻辑并逐项报告结果。
3. 手动还原：用上面的 `update-source.backup.bin` 覆盖回 `%APPDATA%\Delta NFD\update-source.json`；若状态文件记录原值不存在，则直接删除该 json。

恢复是幂等的。若检测到 `update-source.json` 已被第三方（用户或其他程序）改动到既不是本插件写入的内容、也不是原始内容，插件**报告冲突并拒绝覆盖**，保留原有证据与待恢复标记，交由人工处理。卸载、升级宿主或插件升级前，宿主会先恢复再停止；还原失败时宿主保留包与记录，不会假装成功。

## 脱机限制

不支持脱机移交。即使宿主开启「允许插件在脱机模式下运行」，本插件未声明 `offlineAutonomous`，不会被移交给自主后端；脱机模式下宿主退出后，本插件不会有任何常驻进程。

## 权限用途

| 权限 | 实际用途 |
| --- | --- |
| `files.modify` | 改写上面的 `update-source.json`，并把原文件备份到插件数据目录 |
| `network.access` | 访问 gh-proxy 节点做连通性/延迟探测，并通过它读取公开的 GitHub 发布清单 |
