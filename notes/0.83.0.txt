OpenAlphaV0.83 更新内容：

升级说明：0.82.0 及更早版本没有本轮更新器，需要先手动安装此版本；后续更新仅在已发布版本高于本机时提供。
验证说明：编译及后端检查已通过，真实安装/卸载端到端尚待隔离虚拟机验证。

· 帧格新增「前台加速响应」：系统后台资源预留降低 + 前台游戏优先调度，退出帧格自动还原
· 帧格新增「降低省电延迟」：网卡省电全禁 + 关闭 USB 选择性暂停，退出帧格自动还原
· 内存清理卡片新增「可能导致性能下降」红色提示标签
· 改进卸载清理：先确认安装目录内进程退出；保留备份时复制并校验，失败保留原数据；清理不跟随目录联接
· CPU实验室「CPU 亲和性」支持 Intel 大小核：正确识别 P 核 / E 核，新增「仅 P 核」「仅 E 核」快捷键，核心勾选项标注 P/E
· 着色器健康检测新增 PARC 判定：N 卡在 SM6\DXCache 检测到 .parc 文件即直接判为着色器异常
· 安装包内置默认背景图；主页隐藏「优化检测」分数栏目；着色器页移除运行库提醒
· 标题栏显示当前版本号
· 新增软件更新：读取 GitHub 已发布最高版本（包含 Alpha），仅安装高于本机的版本；支持配置备用源，同版本不重装、低版本不降级
· 更新安装器沿用现有安装目录，执行前重新确认最新版并校验安装包大小与 SHA256，持锁防止替换
· CPU实验室新增「优化方案」保存 / 分享 / 导入：导出为 txt（含 CPU 型号、核心数、线程数、异类调度策略、CPU 亲和性），可分享给同款 CPU 的人导入；导入时校验 CPU 型号与核心数/线程数完全一致，不一致拒绝导入
