## Beta0.9191 公测版

- 改进 C++ 14.x 扫描与重装：覆盖 HKLM/HKCU、32/64 位登记，补充动态 MSI 家族识别与卸载前身份复核，减少旧版 2026/v14 环境中的漏检。
- 在卸载完成后、安装固定 14.42 基线前，自动备份并受控清理核验过的旧 v14 INF 包装和孤儿登记；缺少或失效的卸载命令转入清理评估。身份不符的条目保留并说明。
- 修正带引号和无路径卸载命令的解析；无路径命令解析为完整路径后执行并记录。明确启动失败时归档证据，固定旧 INF 已删除时可继续清理剩余登记，备份按注册表位置分别保存。
- 调整兼容性提醒：红色由真实安装的 14.51/v14 MSI 组件触发；包装和残留最高黄色，匹配已核验组件的同版本包装正常，Appx 系统组件仅作说明。主页与运行库页共用结论。
- 软件继续自带 .NET 8 x64 和六个官方后端；内存回收等其他功能延续 Beta0.919。

### 安装与使用

Windows 10/11 x64。公测与内测通道均可接收 Beta0.9191；同号本地版本请手动安装。

运行库属于系统共享组件。全量重装会按确认清单处理检测到的 x86/x64 C++ 14.x，包括有登记卸载命令的未知包装，再安装 Microsoft Visual C++ 2015–2022 14.42.34433 双架构原包。依赖更新版运行库的软件可能需要重新安装其要求的版本。操作前须手动关闭工具的运行库防护；失败、需要重启或结果未知时停止，不强杀安装器。

兼容性颜色是本项目三角洲兼容性策略，不代表已证明所有电脑掉帧或文件损坏，不保证重装可提升帧率。未处理 2005–2013、ARM64、Appx、DirectX 或系统 DLL 手动删除。
