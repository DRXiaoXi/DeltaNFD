# 滚动页面最大化右移复现修复

用户再次提供最大化的“游戏改动”页截图，内容仍右移且右侧被截断。前轮只调整导航对齐并给显卡页加外层容器，未覆盖其余同结构页面；前轮无窗口夹具还替换了真实导航模板，不能验证现场布局。本轮保留前轮记录并补做对照。

## 根因与修改

原生 ScrollViewer 直接包含设置 MaxWidth 的 StackPanel 时，宽视口下出现期望宽度与排列宽度不一致：测试中的游戏改动面板 DesiredSize.Width 为 868，实际排列宽度为 1440，滚动内容却按较小的期望宽度居中，额外右移约 286 DIP。真实隐藏 Window、NavigationView 和 XamlRoot 中可稳定复现；截图中的超宽页面与该现象一致。

统一给 17 处同类滚动内容添加占满视口的 Grid，再由内部原面板保持 1040 / 1200 / 1440 的限宽。两处恢复页及插件入口补齐缺少的横向 Stretch/禁用横向滚动设置。显卡页前轮已加同样的容器，本轮保持，包括新显卡轮廓图标；MainWindow 也未再次修改。

修改页面：ACE、主页、帧格、游戏改动、显卡优化、调度改善、低内存引导、NVIDIA 设置、钟摆、插件入口、插件列表、运行库、设置、着色器维护、着色器恢复、系统优化、计时器恢复。未改业务 C#、事件、绑定、原控件名或面板内部内容；逐页移除新增容器后与本轮前快照的 XML 结构/属性完全一致，另核验已无直接限宽的滚动内容。
