## Beta0.919 公测版

- 重做 C++ 14.x 修复流程：先展示完整卸载计划，确认后逐项处理，再安装内置 Microsoft Visual C++ 2015–2022 14.42.34433 x64/x86 原包并复检组件与实际 DLL。
- 处理范围包括检测到的 x86/x64 14.x MSI、签名包装及有登记卸载命令的未知包装。缺少可执行命令或 ARM64 的条目保留并说明；不再提供旧版包装单独清理入口。
- 保留管理员检查、手动关闭防护要求、安装事务忙与待核对检查、活动记录和日志；失败、需要重启或结果未知时停止。已登记 14.42 包装时使用固定原包 `/repair`，避免只返回成功却未补回组件。
- 保留 14.51 或 Visual C++ v14 名称红色、其他非 14.42 的 14.x 黄色兼容性提醒，以及运行库防护和旧防护恢复入口。
- 延续 Beta0.917 的内存回收缓存范围、进程规则保护、帧格联动及 NVIDIA 着色器缓存大小提醒。软件继续自带 .NET 8 x64，不提供产品 .NET 检测或修复。

### 安装与使用

Windows 10/11 x64 安装包自带运行时及六个官方后端。公测和内测通道均可接收 Beta0.919；同号本地版本请手动安装。

运行库为系统共享组件。14.x 全量重装包括未知登记包装，执行前请检查确认清单；依赖更新版运行库的其他软件可能需要重新安装其要求的版本。兼容性颜色是本项目策略，不代表已验证所有电脑掉帧或文件损坏，也不保证重装能提高帧率。

### 验证与源码

新版 VC14 策略、内存回收、待核对恢复、更新通道及退休功能检查通过；自包含部署和六个后端的实际启动、握手及只读接口检查通过。未执行系统运行库重装、安装器安装/卸载或游戏性能的全面端到端验证。

安装包使用此前已验收的本地 Beta0.919 原文件；其程序集信息版本带构建前的基准提交后缀，功能源码以本次 v0.919 标签与源码附件为准。源码附件补充默认背景与构建说明，排除本机私人日志、研究资料和退休归档。原创代码采用 GPL-3.0-only，微软原包及其他第三方内容保留各自条款。附件大小与 SHA256 见 update.json 和 SHA256SUMS.txt。
