# Alpha0.9195 源码与构建

此源码对应本地Alpha0.9195测试版，数值版本0.9195，完整运行库页启用。源码分支为`codex/alpha09195-source`；此次仅上传源码，不创建GitHub Release、不上传安装包、不调整在线更新清单。

## 当前实现

- V14单独修复及全量修复保留；全量修复先处理微软2005–2013原包和辅助组件，随后连续执行V14受控卸载与14.42安装。旧强力模式已移除。
- 确认缺失14.x后可以直接补装；部分安装失败保留待安装记录。实际组件身份、依赖及DLL均需复检，不能仅凭安装器退出0报告完成。
- 残缺自身包装登记可由精确已核验原包补齐缺字段；未知引用或非空身份冲突仍拒绝。微软14.32原包仅用于已知孤立引用的只读归属证明，不执行、不安装；安装基线仍是14.42。
- 普通修复后DLL版本仍不匹配时，满足固定媒体与已安装身份核验才进入原始MSI强制文件重装步骤。
- 提供用户确认的进程占用处理、可选安全模式引导和安全模式临时Installer启用及恢复。无真实用户逐次确认不会自动重启、结束应用或修改服务。
- 更新默认自建服务器、仅替换变更文件；可手选服务器和全量更新。文件更新失败满足恢复条件时自动回退全量，取消不触发回退。
- 手动BUG反馈客户端及私有接收服务源码分别位于应用Services和`server/feedback`。

## 环境与资源

需要Windows x64、.NET 8 SDK、Windows App SDK构建环境、PowerShell 7及Python 3.11+。资源准备脚本需要7-Zip；EXE安装包由Inno Setup 6生成。

第三方原包保留各自许可。Git中已有固定14.42双架构原包`src/DeltaNFD/Assets/Vc14Baseline14.42`，其SHA256仍由执行库固定校验。以下资源二进制按现有规则不加入Git，需要在完整发布前准备：

```powershell
# 下载固定微软2005–2013原包并提取其原始MSI/CAB；不执行安装器。
python tools/prepare-runtime-cpp-official.py

# 从仓库已有固定14.42原包提取强制文件重装的原始媒体。
python tools/prepare-vc14-file-repair.py

# 下载并核验仅供归属证明的固定微软14.32原包。
./tools/prepare-vc14-ownership.ps1

# 从已核验Alpha0.916的旧资源中复制辅助组件；保留本分支脚本和过滤清单。
python tools/prepare-runtime-highfps.py <Alpha0.916的Assets/VCRedistRepair路径>
```

最后一步的旧资源须匹配脚本固定的原清单哈希；当前过滤清单只保留UCRT、VB及VSTO辅助组件，不恢复旧2005–2013或C++2026安装步骤。完整发布还需要本地默认背景`src/DeltaNFD/Assets/background.png`；该图片按现有忽略规则不加入Git。

## 构建和验证

```powershell
dotnet build src/DeltaNFD/DeltaNFD.csproj -c Release -p:Platform=x64
dotnet build tools/BackendSmokeTest/BackendSmokeTest.csproj -c Release

# 逻辑与隔离检查，不执行系统运行库安装/卸载。
dotnet run --project tools/BackendSmokeTest -c Release --no-build -- --vc14-staged-checks
dotnet run --project tools/BackendSmokeTest -c Release --no-build -- --vc14-checks
dotnet run --project tools/BackendSmokeTest -c Release --no-build -- --vc14-ownership-checks src/DeltaNFD/Assets/Vc14OwnershipOriginals
```
