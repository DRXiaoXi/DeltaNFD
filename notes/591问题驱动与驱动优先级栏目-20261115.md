硬件列表使用 SetupAPI 枚举当前 PCI 设备；通过设备属性读取中断支持位和消息数上限，使用 Config Manager 的 allocated resource 配置读取 IRQ。已对照本机 Windows SDK 10.0.26100.0 的 `pciprop.h`、`devpkey.h` 和资源描述结构核对 GUID、属性号、类型、布局和偏移。未知、读取不完整或驱动身份不足的设备只能查看；不将读取失败推定为默认值。

仅支持固定设备实例下的以下三项 DWORD，不接收前端指定的注册表路径或脚本：

| 设备实例相对路径 | 值 | 行为 |
| --- | --- | --- |
| `Device Parameters/Interrupt Management/MessageSignaledInterruptProperties` | `MSISupported` | MSI 启用／禁用；必须核对硬件能力；不允许对没有线中断支持的设备强制关闭 MSI |
| 同上 | `MessageNumberLimit` | 留空或 0 恢复驱动默认（删除该值）；非零受硬件上限约束，普通 MSI 仅允许 1/2/4/8/16，MSI-X 不超过 2048 |
| `Device Parameters/Interrupt Management/Affinity Policy` | `DevicePriority` | 默认删除该值；低／正常／高分别为 1/2/3 |

这些是中断配置，不等同于帧格的目标进程 GPU 调度优先级或 NVIDIA 前后台资源比例。消息上限和高优先级也不承诺性能收益。

## 写入与恢复

原始值保存在软件数据目录 `%APPDATA%/Delta NFD/DriverPriority`，不放到设备、游戏或原工具目录。记录区分值不存在与 DWORD 0，并绑定本机、用户、设备实例及驱动身份。每次写入前持久保存原值、写前值和预期值；后续修改保留最初仍由本工具负责的原值。全局互斥覆盖修改和批量恢复，备份文件在原生写入及回读期间保持打开以避免中途被替换。

提交前重读设备与配置、校验列表指纹，并复核管理员权限、游戏退出和恢复门禁。写入只申请固定中断管理子键的权限，不接管 ACL、不禁用或重启设备。每项及整体写后都回读；失败、中断、设备断开、身份改变、磁盘故障或外部变更均保留恢复责任，不报完整成功。

恢复仅处理仍能与原始／写前／预期值匹配的本工具字段；遇到外部修改不覆盖，其他可确认字段仍尝试恢复。每项恢复后更新持久记录，全部完成才归档。后端核对、范围恢复和未确认操作归档接入 `driver-priority` 范围；其他范围恢复成功不能消除本范围的责任。没有此目录或没有记录时，不因后台核对枚举 PCI 设备。
