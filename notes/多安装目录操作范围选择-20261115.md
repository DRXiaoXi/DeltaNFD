# 多安装目录操作范围选择（2026-11-15，本地 r12）

游戏改动、着色器维护、ACE 栏目的手动操作增加安装范围选择。仍为 Alpha0.935 / 0.9350，不改线上通道。

## 玩家操作

- 识别到两个及以上三角洲安装目录时，先选一个完整路径，或“全部 N 个三角洲目录”；不预选，默认取消。
- 同一份安装的父目录与 DeltaForce 子目录、路径大小写差异在选择清单中合并。选择仅对本次操作有效，不改变登记目录或默认游戏。
- 自动进入页面的只读概览仍可汇总；手动刷新、着色器检测和 ACE 游戏/CORE 检测先选范围。
- 全屏优化按所选安装主程序执行。录制组件按当前按钮对应的组件，在所选安装逐个备份、替换或恢复；确认框列出实际文件和状态。已达到目标状态的组件跳过，状态不明先拒绝，执行失败停止后续目录。
- 着色器单目录仅清本地 PSOCache；选择全部并确认后，621 驱动仍联动当前用户 D3DSCache。显式系统缓存清理、恢复页中选择驱动缓存时属于共享操作，需选择全部并确认。选择全部的健康检测逐个检查 PSOCache，不再只检查第一份安装。
- ACE 按用户明确选择的“单目录只清本地 ACE，全部目录时再确认共享清理”实施。单目录只删除该安装内固定位置的 AntiCheatExpert，保留共享进程、服务、驱动、注册表与系统安装目录；不结束进程、不安排重启删除。占用、权限、链接等未完成项如实报告，仍要求退出游戏和守卫。
- 共享 ACE-CORE SYS 无法按安装隔离，只可选择全部并再次确认。单安装检测不把共享 CORE 总数与所选子集数量比较，不因此报共享冗余；其他手动 ACE 游戏记录保留。

## 后端范围与兼容

`GameInstallationSelection` 携带清单指纹、规范根、显式全部与共享确认。后端重新读取完整已知清单；清单变更、未知路径、重复路径、伪造“全部”、单目录夹带共享授权均在操作前拒绝。多目录旧式修改请求没有选择时也拒绝。

`GameInstallationScope` 用调用方不能改写的异步操作快照限制共享定位器，不改玩家持久配置。后台只读线程按每次请求捕获 ExecutionContext，线程启动不继承首次调用的范围；并发任务不会串用目录。

后端 ready 增加可选 `GameInstallationScopeVersion`，仅完成范围实现的 ACE/系统模块声明版本 1。旧消息缺字段视为 0；当前客户端在发送含目录选择的请求、登记写前意图之前核对能力，不支持时明确拒绝，防止旧后端忽略选择后按全部执行。严格 ready 解析继续拒绝其他未知字段、错误类型和不兼容版本。必须使用完整安装包，不提供单 DLL 补丁。

录制组件单目录读取时，其他安装的恢复记录保留，但不再让本次页面因范围之外的记录永久不可操作；全部范围的旧未知记录核对与全局恢复流程保持。
