# 帧格 GPU 调度与 NVIDIA 前后台比例（2026-11-15，源码改动）

按用户选择加入两个独立开关，默认均关闭，位于帧格原有 CPU / IO / 内存优先级卡片之后。仍为 Alpha0.935 / 0.9350。本轮遵照“还要改别的，不需要压缩”，只修改源码、编译和检查，不生成安装包或压缩文件。

## 玩家可用的设置

- **目标游戏 GPU 调度优先级**：高、高于正常、正常、低于正常、低。使用既有 Windows GPU 进程调度接口，不开放实时档。帧格启用且目标游戏运行时生效；自定义游戏模式按所选 EXE 的完整路径、PID、创建时间及目标代次核对，同名异目录进程不纳入。
- **NVIDIA 前后台 GPU 比例**：前台优先 90/10、默认 80/20、后台优先 50/50，另可填写后台整数百分比。对应本机 NVIDIA App 的后台 YieldPct 值分别是 10、20、50，前台显示为 100 减去后台值。实际可写值须符合驱动返回的预设掩码或范围与步长，界面 0～100 的输入范围不等于驱动支持所有值。
- 两项分别配置、分别执行；在帧格开启期间按既有规范锁定选项。NVIDIA 比例属于全局偏好，会影响其他应用，不保证实际利用率或独占资源。需实际生效的 HAGS、支持此项的驱动和已安装的 NVIDIA App；不自动修改 HAGS。
- 先记录实际原值、写入后回读。目标游戏结束、关闭帧格、停止监控、全部恢复和退出工具都包含恢复；某一项恢复失败仍尝试另一项。恢复失败保留责任记录，不能显示成功。外部 NVIDIA App 改动优先，工具归档原记录并停止本次接管，不反复抢写。

## NVIDIA 接口依据与兼容范围

仅静态检查本机 NVIDIA App 11.0.9.585 的界面逻辑及 `NvCplDisplayPlugin.dll` / `nvcpl.dll`，未执行或加载这些 DLL。固定 ABI：`NvCplApiInit(0, 0)`；`NvCplApiGetSetting` 查询 scope=1、target=0、id=0x346、32 字节 v1 结构；`NvCplApiSetSetting` 写 id=0x347、16 字节 v1 结构，检查 Written / Error 并再次查询。

此接口没有本轮查到的公开稳定合同。因此产品实现仅允许玩家本机 `Program Files/NVIDIA Corporation/NVIDIA app/NvCpl/nvcpl.dll`，同时验证非重解析路径、可信 NVIDIA 签名、ProductVersion=11.0.9.585、SHA256=`a7703de492d47d4e75d6f77e7350a860b927f35be719b5e78a94e4d50d236da1` 后才动态加载。其他安装库版本明确拒绝调用，提示使用 NVIDIA App 或等待更新兼容清单。默认关闭时不加载此库，不创建全局锁。不复制或分发厂商 DLL，不修改厂商二进制。

显卡身份使用正常 NVIDIA PCI 设备的 PNPDeviceID 集合摘要，不用可伪装的显卡显示名称。WMI 枚举设有 2 秒超时。全局独占文件锁避免多个工具实例同时调整；原值记录还绑定硬件身份，换卡后不把旧原值写入另一张卡。尚未回读成功的写入记录单独标记，异常当前值不能直接当作外部变更而丢弃责任。

微软 [GPU 调度类枚举](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/d3dkmthk/ne-d3dkmthk-_d3dkmt_schedulingpriorityclass) 为本工具采用的 0～4 档位依据；[NVIDIA 官方说明](https://blogs.nvidia.com/blog/local-ai-rtx-spark-laptops-updates-models-agents-games/) 说明 App 的 GPU 资源分配入口及 HAGS 前提。上述私有 ABI、预设数值和精确库身份来自本机文件的静态证据，不把官方介绍解释为该 ABI 的支持承诺。

## 执行与恢复

进程 GPU 调度复用既有优先级控制器的身份钉住、属性归属、写前记录、回读、拒绝后不连续重试和恢复流程。手动及规则对同一属性的设置优先；独立关闭 GPU 项不恢复仍启用的 CPU / IO / 内存项。

NVIDIA 比例记录为数据目录中的 `frame-nvidia-gpu-share.json`，保存实际原值而非固定默认值。原子写入并刷新磁盘后才能提交设置，成功回读后另行标记已确认。全局锁位于受保护的 ProgramData 子目录，权限只允许管理员和 SYSTEM。此原生锁路径仅编译与代码检查，未在宿主创建或实测。记录损坏、硬件不符、读取失败或恢复回读不一致均保留记录。恢复记录纳入后端未完成计数、全部恢复、退出清理及恢复出厂前证据保全。

两项状态合同分别标注版本 1。界面核对后端模块、父子快照新鲜度、实际回读和监控运行状态；旧后端或过期快照不显示成功。NVIDIA 单独启用也会启动监督循环，停止钟摆不会错误停止此循环。
