# 内存回收目标保护与后台执行改进（2026-11-15）

范围：`_br222/s` 当前 Alpha0.935 / 0.9350；仅源码、隔离测试和完整产品编译，不生成安装包或压缩文件。

## 行为变化

- 普通、稳洲回收同时保护当前所选游戏与原三角洲主进程。自定义目标按规范完整路径保护全部实例，处理路径别名及大小写；同名异目录不误判成所选目标。目标路径无法确认、设置与后端目标不一致时拒绝逐进程回收。预览绑定目标代次；执行期间持有目标操作租约，在原生写前再次检查目标与设置。激进模式继续保留用户授权的全局范围。
- 自动回收由独立任务串行执行；手动、自动、激进共用一个执行名额，忙时不排队重放。枚举与原生回收不持有引擎共用锁，原有规则/帧格监督循环继续推进。普通模式仍持有跨进程属性归属锁，原生调用保持同句柄身份核验及回读；守卫不反向获取引擎锁，避免锁顺序冲突。
- 停止监控先阻止新任务、取消活动任务，再等待已进入的系统调用结束后完成恢复。停止期间禁止重新启动或保存参数重新激活；配置版本变化使旧工作永久失效，即使切换模式后又切回来也不会复活。所有异常路径释放执行名额。不能中断已经进入的 Windows 同步系统调用，也不声称工作集回收可以还原。
- 一轮自动回收复用候选枚举，不再执行第二遍全进程枚举。移除守卫里重复的 PID/工作集读取，保留原生同句柄写前读取；压力检查走轻量物理内存查询，前后结果仍读取完整物理内存/提交量。单候选模拟由两遍枚举、三次外层工作集读取，变为一遍枚举、一次读取；这不是实际 CPU 或帧率收益测量。
- 压力仍每30秒采样，高压确认和原冷却条件保留。空候选也按用户设置的间隔限制候选扫描，不再每30秒重新全量枚举；修改参数后重新评估。没有增加无效/回涨后的额外退避，也没有加入磁盘活动监测、稳洲逐目标延时、CPU门槛或工作集大小门槛。
- 更新普通/稳洲保护说明及压力/候选扫描间隔说明，页面控件、绑定、操作事件和数值范围保持。
