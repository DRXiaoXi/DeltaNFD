# 钟摆计划 Win10 与 Win11 恢复开放

用户要求重新开放 Win10 实验，并明确选择“Win10 与 Win11 一起恢复”。仍在 `_br222/s` 开发分支本地处理，没有发布或更改版本。

## 修改

- 共享 `ReleaseFeaturePolicy.PendulumEnabled` 恢复为 true，前端、进程管理后端、系统配置后端沿用这一共同策略。导航“钟摆计划”移除 Collapsed，帧格页增加精度锁定随帧格启停及先检测/扫描的说明。
- Win10 1809+ 保留实验标识、无 CPU 负载的兼容检测、扫描内再次实测和带平台归属的扫描记录。Win11 保留全局精度设置备份、实际重启核对及锁定效果验证；不改变支持范围、算法、记录格式或后台监督。
- 帧格“忽略精度请求”的策略仍为 false；解除钟摆隐藏不会连带开放它。原释放/恢复路径保持，扫描与帧格的锁定归属保持。
- 更新公开范围测试：验证恢复后的前置条件、旧 Win10 不匹配扫描不能持有、未满足条件释放旧持有、帧格关闭后的释放和仍隐藏的忽略请求功能。测试不再调用真实全局设置入口。Win10/Win11 两组原引擎测试移除强制开放测试开关，验证实际发布策略即可进入原有受控路径。
