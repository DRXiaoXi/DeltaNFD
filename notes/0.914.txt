Alpha0.914（内部版本 0.914）

本版本向内测通道发布；公测通道继续接收 Beta/Release。

- 新增进程管理：查看进程 CPU/内存及实际属性，调整 CPU 优先级、亲和性、CPU 集合、效率模式、动态提升、I/O、内存和受支持的 GPU 调度优先级。
- 属性操作用“当前 / 总是”区分本次进程与持续规则；支持编辑、停用、删除规则，并按备份恢复。GPU 首选项由 Windows 按应用保存。
- 新增“后台抑制”：高负载时临时降低合适后台进程的优先级，负载回落或关闭后恢复；排除三角洲主进程、系统进程、前台应用及已有手动属性设置或启用规则的进程。
- 重排进程管理界面，修复列表与详情重叠，改善窄窗口布局、CPU 选择和自动刷新编辑状态。
- 主页新增工具所需 .NET 环境检测；安装包携带微软 .NET 8 x64 离线修复包，设置页和开始菜单均可进入修复。
- 未确认的后端操作在错误弹窗直接提供核对、恢复和重试入口；保留真实未知证据，避免让用户自行寻找设置入口。
- 运行库修复增加进度与步骤反馈，新增“卸载全部 C++ 运行库”；兼容性修复共用高帧性修复的受控卸载阶段，再修复 DirectX、安装 C++ 并复检。
- 修复旧版 C++ WinSxS 组件复检、条件组件识别、重启后的继续流程与恢复等待预算。
- 修复帧格电源快照归属、隐藏电源设置读取、旧备份核对及迟到还原和退出超时竞争。
- 收紧 ACE 清理注册表范围，核验备份与路径归属；修复卸载登记键、缩略图清理范围、启动更新探测阻塞等问题。
- 新增签名紧急策略包接收机制，用于调整内置算法参数或停用故障功能；不下载执行任意 C#/DLL。

内存优先级使用 Windows 支持的文字档位；部分 GPU/系统能力以实际读取和权限为准。未执行真实运行库安装/卸载或用户系统恢复，相关流程通过隔离故障测试；实际安装升级请保留日志反馈。
