# Alpha0.935：一键准备 Win10 钟摆驱动

用户要求将截图中的手动准备流程自动化。本轮在 `_br222/s` 实现并生成本地 r3 安装包；显示版本 Alpha0.935，内部版本 0.9350。根目录旧产品源码、此前成品和 Git HEAD/索引保持，不上传、不更新线上通道。

## 玩家流程

- Win10 1809+ x64 的钟摆页新增“一键准备 / 继续”。确认框默认取消，明确列出测试模式、Root/TrustedPublisher 测试公钥信任及重启后的驱动操作；安装主程序本身不代表授权。
- 按固化 SHA 核验 SYS、公钥、原始 BOM 脚本及清单，并保留拒写/拒删除读句柄。先耐久记录授权、用户/启动身份及原状态，导出 BCD 并记录 SHA，再按需执行固定 `bcdedit /set {current} testsigning on`，导入精确公钥并回读。
- 需要时由玩家保存工作、通过 Windows 开始菜单手动重启，再打开软件。无 RunOnce、自启动登记或强制重启。启动续办只执行原授权的驱动安装/启动及数值检测保存，不再次修改启动配置或补回后来撤销的证书。准备完成后主动移除驱动时，也不会自动重装。
- 重启后的 CI 标志、原生按需服务路径、保护记录及已安装 SYS 身份仍须全部通过；随后沿用原 0.5ms/1ms 驱动数值检测、持有/释放和保存回读。无需手输命令，不以 Sleep 或 CPU 压力准入。Win11 和前轮精度请求忽略功能保持。

## 中断与边界

专用授权记录位于 `%ProgramFiles%\DeltaNFD Pendulum Preparation\state.json`；BCD 原备份为同目录 `bcd-before-<编号>.bcd`。目录和新文件设为 Administrators/SYSTEM 可写，额外核对所有者和 ACL；拒绝重解析、损坏身份、其他用户和不匹配包。SYS、脚本和证书均是既有自研测试签名输入，没有添加私钥或引入 DPC/PawnIO。

每次启动固定子进程前先记意图，再记录 PID/创建时间/启动 GUID；20 秒未确认结束不杀写入进程，保留身份并报未知，禁止重复启动。部分完成保留阶段及备份，重复已确认步骤幂等。结果未知仍接既有后端核对，不可借其他系统优化恢复范围清除；成功的静态准备按原静态备份规则落定。该机制不保证所有断电/存储损坏都可自动恢复。

不自动关闭安全启动、内存完整性、磁盘保护，不整库导回 BCD，不删除原本已有的信任或关闭原本已启用的测试模式。系统策略阻止时停止并给出原因。退出实验环境仍按随包说明人工卸载、核对精确证书和恢复原启动设置。测试签名不是微软生产签名；反作弊环境仍需真实验收。
