Beta0.91（内部版本 0.91）

- 运行库新增高帧性修复与兼容性修复，保留 Beta0.9 完整 C++ AIO 流程及新版防护；兼容性修复独立处理 DirectX 旧版组件和 C++ 依赖。
- 两种修复共享强力模式，加入 Windows 系统组件修复和独立进程 API Sets/UCRT 抽查；修复中文 SFC 结果识别、同版本 C++ 文件覆盖/哈希复核及待重启状态处理。
- 更新设置新增内测/公测通道：内测接收 Alpha、Beta、Release，公测接收 Beta、Release。首次 Beta 安装默认公测，Alpha 安装切回内测，Beta 重装保留已有选择。
- 修复运行中安装的管道等待竞态、中文交接报告乱码和异常反馈；不误启动旧程序，不强杀未完成的恢复事务。
- 安装、卸载及自动更新统一安全交接；改进后端停止、迟到还原、恢复记录核对、Defender 临时状态恢复、脱机模式关闭及 ACE 清理结果处理。
- 自本版本起原创内容采用源码可用非商业许可证，禁止收费转售、闭源二次开发、用于收费产品、商业使用及删除作者署名。历史 GPL 授权与第三方内容的原授权不变。

安装包包含主程序、五个官方后端、脱机助手、自包含运行时及运行库修复资源。旧版较高内部编号的本地测试安装不会自动降级，可按需手动安装本版本。
