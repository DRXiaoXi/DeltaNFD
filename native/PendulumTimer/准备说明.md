# Alpha0.935：Windows 10 钟摆驱动准备

仅适用于 Windows 10 1809 及以后版本的 x64 系统。Win11 沿用原有钟摆路径，无需此驱动。随包自研驱动具有实验用测试签名，没有微软生产签名。开启测试签名模式会改变驱动校验策略，反作弊兼容性尚未验收；请先确认游戏允许此环境。

程序安装器只复制驱动文件，不会安装或加载内核服务，不会自动导入证书、修改启动设置或重启。安装完成后，可在钟摆页主动确认“一键准备 / 继续”。未完成准备时，Win10 钟摆的检测、保存和持有均被阻止，帧格其他功能仍可使用。

## 推荐：一键准备

1. 退出三角洲，以管理员身份打开 Alpha0.935，进入钟摆计划并点击“一键准备 / 继续”。确认框会列出证书信任、TESTSIGNING 和后续驱动操作；默认取消。
2. 确认后程序核验随包 SYS、公钥、清单和原始脚本 SHA，先记录原状态并导出 BCD，再按需开启 TESTSIGNING，将精确公钥加入本机 Root 和 TrustedPublisher。文件、签名或系统策略不符时停止，保留具体原因。
3. 提示重启后，请保存工作，通过 Windows 开始菜单手动重启。再次打开软件，将按原授权自动安装或启动已核验的自研驱动，检测并保存 0.5ms 或 1ms 持有值。已满足测试模式和信任的机器无需再次重启。

不新增开机任务或 RunOnce；需要重新打开软件。不会自动关闭安全启动、内存完整性或磁盘保护，不强制重启。本次启动必须实际启用测试签名，不能只凭 BCDEdit 成功就开放驱动功能。自动检测不运行 Sleep 或 CPU 负载测试；开启帧格后才长期持有。

授权与准备阶段记录在 `%ProgramFiles%\DeltaNFD Pendulum Preparation\state.json`，BCD 原件位于同目录 `bcd-before-<记录编号>.bcd`，仅管理员/SYSTEM 可写。记录包含原信任是否存在、原启动是否处于测试模式、各步尝试以及未结束子进程身份。中断后不重复启动存活或身份不明的写入进程；保留记录和备份。不要删除记录绕过核对。

重启后自动续办不会重新修改 TESTSIGNING 或导入已撤销的信任，也不会重新安装已完成准备后被主动移除的驱动；需要再次点击并确认。记录损坏、属于其他用户或文件/服务身份冲突时停止。BCD 备份用于人工核对，不自动整库导入覆盖其他启动修改。退出实验环境仍按下方说明手动恢复；不会擅自删除实验前已有证书或关闭原本启用的测试模式。

## 备选：手动首次准备

在本文件夹中以管理员身份打开 Windows PowerShell。先核对随包 `driver-package.json`，公钥证书指纹应为 `C28A9EF423B20DA4A9F0F0F7BD0147C31D0A95FE`，驱动 SHA256 应为 `9A7E35234617B1D4A86A0DDDEB0A819821189B18783028CEECB6DB4591F65522`。

```powershell
Get-FileHash -LiteralPath .\DeltaNFDPendulumTimerV1.sys -Algorithm SHA256
certutil.exe -dump .\DeltaNFD-Pendulum-Test.cer
```

确认来源和指纹后，仅在自愿使用此实验环境的机器上执行：

```powershell
certutil.exe -addstore Root .\DeltaNFD-Pendulum-Test.cer
certutil.exe -addstore TrustedPublisher .\DeltaNFD-Pendulum-Test.cer
bcdedit.exe /set testsigning on
```

随后通过 Windows 开始菜单**手动重启**。仅看到 BCDEdit 操作成功不代表本次启动已经生效。若系统报告该设置受安全启动策略保护或其他错误，请停止准备；本工具不会替你修改固件安全、内存完整性或磁盘保护设置。

重启后回到本文件夹，以管理员身份执行：

```powershell
Get-AuthenticodeSignature .\DeltaNFDPendulumTimerV1.sys | Format-List Status,StatusMessage
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\Setup-Driver.ps1 -Action Install
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\Setup-Driver.ps1 -Action Status
```

签名应为 Valid，驱动应启动成功。打开 Alpha0.935 的钟摆计划，点击刷新；全部准备检查通过后，先仅检测，再检测并保存持有值。开启帧格时持有，关闭帧格或退出工具时释放。检测只核对驱动授予和系统分辨率，不检测 Sleep 或游戏效果。

## 已安装与故障处理

重新启动 Windows 后，按需驱动不会自动加载，执行 `-Action Start` 再刷新即可，不要重复 Install。旧实验包出现路径错误 123 时先执行 `-Action RepairPath`，再执行 Start；该操作核对原文件与记录，不会删除重装未知服务。

错误 577 表示内核拒绝签名，保留错误并核对测试签名模式是否已随重启生效。不要将 Authenticode 的 Valid 当作必然可加载；内核策略仍可拒绝。记录损坏、文件或服务路径变化时，请保留现场，不要删除记录绕过保护。

服务名为 `DeltaNFDPendulumTimerV1`。驱动与准备记录保存在 `%ProgramFiles%\DeltaNFD Pendulum Driver`。安装前该位置已有未知内容时，脚本会拒绝覆盖。

## 停用和恢复原环境

先关闭帧格并退出工具，再以管理员身份执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\Setup-Driver.ps1 -Action Remove
```

确认驱动已移除，且此证书没有用于其他实验后，按精确指纹移除两处测试证书：

```powershell
certutil.exe -delstore Root C28A9EF423B20DA4A9F0F0F7BD0147C31D0A95FE
certutil.exe -delstore TrustedPublisher C28A9EF423B20DA4A9F0F0F7BD0147C31D0A95FE
```

若本次实验前测试签名模式为关闭，执行 `bcdedit.exe /set testsigning off` 并手动重启，恢复原环境。原本已为其他工作开启时，应恢复你原有的配置，不要贸然关闭。卸载主程序不等于已完成上述实验环境清理。
