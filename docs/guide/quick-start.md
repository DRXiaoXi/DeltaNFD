# 快速上手与环境整备指南

欢迎使用 **DeltaNFD（三角帧不掉洲）**！本工具由 B 站 UP 主 **逐梦之子-晓夕** 发起并永久免费开源，旨在解决《三角洲行动》因底层着色器缓存机制、反作弊驱动冗余、运行库静默覆盖及异构 CPU 调度不均引发的掉帧与卡顿问题，让你的电脑帧数抵达稳定极限。

::: warning 运行前必看：关闭“智能应用控制”防拦截
如果在安装或使用过程中遇到 Windows 弹窗提示 **“智能应用控制已阻止可能不安全的应用”**，请打开 **Windows 安全中心 → 应用和浏览器控制 → 智能应用控制**，将其切换为 **「关闭」**。同时请确保以 **管理员权限** 运行本工具。
:::

## 一、首次启动与主页体检

1. **定位游戏目录**：首次打开软件时，若弹窗提示“未检测到三角洲游戏目录”，请点击 **「立即定位」**（或手动设置）选择你的《三角洲行动》安装路径。
2. **查看组件检测状态**：在 **「主页」** 下方的状态栏中，软件会自动对 **着色器**、**ACE**、**运行库** 三大核心环境进行体检：
   * 🟢 **绿色 / 正常**：当前环境健康，无需额外操作。
   * 🔴 **红色异常提示**：说明该组件存在直接拖累帧数或引发卡顿的隐患，直接点击右侧的 **「去处理」** 即可跳转至对应页面修复。
3. **一键帧格模式**：主页提供快捷开关，可一键联动 **电源计划锁定、加速系统响应、前台响应加速、降低省电延迟、目标游戏启动时重启 DWM** 等已开启的帧格功能。各项功能仍由帧格页的独立开关控制。

## 二、三大核心环境排障（重中之重）

很多高配电脑帧数甚至不如低配电脑，核心原因往往出在 **着色器、ACE 驱动与运行库版本** 上。请优先把这三个模块处理为绿色正常状态。

### 1. 着色器维护（解决编译掉帧与切换异常）

《三角洲行动》（DX12 模式）对显卡驱动版本与 `PSOCache` 目录极其敏感（仅 DX11 用户此处为空）。当主页提示着色器异常时，请按以下三步处理：

#### 第一步：排查并更换合格的 NVIDIA 驱动

* **驱动要求**：当前版本将低于 **`576.88`** 的驱动判定为过老，建议直接升级到 `576.88` 或更新版本。
* **问题驱动**：**`591`、`592`、`610`、`616`、`617` 系列** 均存在着色器文件缺失风险；`617.14` 是已确认的问题基线。对于高于 `617.14` 的版本，如果单版本缓存中 **≥256MB 的 `.nvph` 文件少于 2 个**，工具也会按驱动异常处理。
* **作者实测推荐**：
  * **RTX 30 系及以下显卡**：推荐 **`576.88`**
  * **RTX 40 系 / 50 系显卡**：推荐 **`596.49`**
* **健康缓存特征**：正常的 S11 赛季 N 卡着色器缓存应为 **无 `0KB` 空文件 + 恰好 2 个 ≥256MB 的 `.nvph` 大文件**。

#### 第二步：清理多版本残留（GameVer 冲突）

更新显卡驱动或修改显卡型号（显卡伪装）后，`PSOCache` 下会生成多个 `GameVer` 文件夹。由于游戏自身的缓存目录切换机制存在缺陷，**只要存在 ≥2 个 `GameVer` 目录，无论 I 卡、A 卡、N 卡，都可能因切错目录导致帧数暴跌**。

* 在本工具 **「着色器维护」** 页面，依次点击 **「一键清除旧着色器」** 与 **「清理系统着色器」**。

#### 第三步：执行标准着色器重预热流程（切勿跳过）

清理完成后，请严格按照以下顺序完成预热：

1. **启动游戏触发预热**：进入游戏等待加载进度条预热。若未自动预热，请进入游戏 **设置 → 画质 → 点击「重新预热着色器」** 并重启游戏。
2. **游戏大厅静置等待（关键）**：进入游戏大厅后不要立刻开始对局。《三角洲行动》会将一部分着色器预热放到大厅后台。请打开任务管理器观察 CPU 占用率，在大厅静置几分钟，直到 CPU 占用率回落到平稳低值。
3. **普坝跑图一局**：大厅预热完成后，进入一局 **普通大坝（普坝）** 跑图，完成二进制任务文件的实战预热。
4. **重启游戏生效**：跑完一局退出并重新启动一次游戏，让新的着色器缓存完整生效。

### 2. ACE 反作弊组件清理（解决局内外周期性顿卡）

当 `C:\Program Files\AntiCheatExpert` 目录下累积了 **≥2 个 `ACE-CORE` 系列 `.sys` 驱动文件** 时，可能引发游戏内外预期之外的卡顿。

* **标准修复流程**：
  1. 进入工具 **「ACE 相关」** 页面。若提示“多版本冗余”，点击 **「一键清除 ACE」**。
  2. **按需重启**：若存在被占用的待删除文件，请按提示重启电脑。
  3. **启动器普通修复**：打开官方启动器或 WeGame，执行 **「普通修复」**，注意不要选择深度修复。
  4. **关于 ACE 预启动弹窗**：修复后首次进游戏可能弹出 ACE 预启动安装提示。请确保没有误拦截该弹窗；如果你在不安装预启动的情况下也能正常进入游戏，作者建议不要额外安装预启动。

### 3. 运行库重装与防篡改守护（解决静默更新掉帧）

经作者实机测试，《三角洲行动》会在后台静默安装最新版 `v14`（2015-2026）C++ 运行库，可能导致游戏帧数下降：

* **`14.42` 版本（工具内置）**：实测帧数最高，操作延迟可能略微增加。
* **`14.40` 版本**：帧数适中，操作延迟最低。

#### 操作步骤

1. **重装内置运行库**：
   * ⚠️ **注意**：重装过程会先卸载系统内现有的 C++ 运行库，这会导致正在运行的依赖 C++ 的软件崩溃。操作前请务必关闭游戏及其他无关后台软件。
   * 点击 **「高帧性修复」**，等待自动卸载旧版并装入内置的 `14.42` 黄金版本。
2. **开启运行库防护模式（防止游戏再次偷偷覆盖）**：
   * **基础 V14（推荐日常常开）**：通过 3 项 IFEO 仅拦截 `vc_redist.x64/x86/arm64.exe` 安装包，不影响日常软件。
   * **完全防护**：拦截全部 11 项 C++ 与 DirectX 安装器，并限制 UE4 前置包权限。
   * 💡 **提示**：开启「完全防护」后，安装 NVIDIA App、显卡驱动或其它需要写入 C++ 的软件可能会被拦截。安装这些软件前，请先关闭防护并点击 **「强制清理拦截」**，装完再重新开启。

## 三、系统优化与硬件深度调优

### 1. 系统优化（优先使用「UP推荐」）

本模块参照 BoosterX 整理了大量底层调优项，新手无需盲目全开，**可直接切换到最右侧的「UP推荐」分类**。下面这些项目收益较高，但仍需按自己的硬件与使用场景勾选，确认后点击 **「应用更改」**：

| 优化项目 | 推荐操作 | 核心作用与注意事项 |
| :--- | :--- | :--- |
| **暂停 Windows 更新 100 年** | ✅ 推荐开启 | 防止后台下载补丁抢占磁盘、网络与 CPU |
| **禁用自动加密（BitLocker）** | ✅ 强烈推荐 | 减少磁盘读写加密开销。请同步前往 **Windows 设置 → 隐私和安全性 → 设备加密**，若处于开启状态请直接关闭 |
| **一键关闭遥测 / 禁用快速启动** | ✅ 推荐开启 | 减少后台遥测上报，避免快速启动带来的内核状态残留 |
| **关闭 VBS / 关闭预读取** | ✅ 按需开启 | 关闭虚拟化安全性（VBS）与预读取可释放硬件潜能；关闭 VBS 后 WSL2、虚拟机等功能将不可用 |
| **禁用内存压缩 / 分页合并** | ⚠️ **内存 > 24GB 建议开启** | 若你的物理内存高于 24GB（如 32GB / 64GB），可关闭这两项以降低 CPU 开销；小内存机器不建议关闭 |
| **关闭鼠标加速 / 禁用 Windows Search** | ✅ 推荐开启 | 还原 1:1 肌肉记忆鼠标轨迹，停止后台索引扫盘 |
| **虚拟内存（页面文件）** | ✅ 手动指定容量 | 不要把页面文件完全交给系统动态管理。建议在底部选择游戏所在或高速 SSD 分区，最小值和最大值均不低于 `16 GB`，常见可设为最小 `16 GB`、最大 `32 GB`，确认后点击 **「应用设置」** 并重启 |

### 2. 显卡伪装（激活隐藏极低画质 + 网吧免重启模式）

通过修改注册表让《三角洲行动》将你的显卡识别为指定低端型号（如 `NVIDIA GeForce GTX 1050 Ti`），可尝试激活游戏隐藏的最低画质档位：

* **常规机器流程**：选择目标显卡 → 选择伪装型号 → 应用伪装 → 删除着色器缓存 → 进游戏大厅静置预热 → 普坝跑图一局。
* **网吧玩家专属**：选择 **「临时模式」** 和 **「立即重载显卡（不重启）」**，工具会尝试禁用并重新启用显卡设备，屏幕会短暂黑屏。该模式无需重启电脑即可尝试生效，机器重启后会自动还原原型号。
* **注意**：伪装只修改注册表中的设备描述字符串，不修改 PCI 硬件 ID 与驱动，也不会改变显卡的真实性能。重载显卡时正在运行的游戏和 3D 应用可能崩溃，请先保存工作。

### 3. NVIDIA 显卡设置（画面清晰度与防掉帧调优）

直连 NvAPI 修改驱动底层 Profile，减少模糊与爆显存掉帧：

* **DLSS 超分模型（SR Preset）**：常用 `F`、`J`、`K` 等选项。
  * **`K`（推荐 Transformer）**：画质与性能较均衡，适合作为首选。
  * **`F`**：旧版 CNN 模型，兼容性较好。
  * **`L` / `M` / `N`**：驱动提供的新模型选项，可在确认驱动支持后自行对比清晰度与性能开销。
* **抗锯齿透明度（透明采样）**：用于改善烟雾、火焰等半透明特效的清晰度，可根据游戏内 DLSS 档位调整：
  * **质量档** → 选择 **`2x 多采样透明`**
  * **平衡档** → 选择 **`4x 多采样透明`**
  * **性能档** → 选择 **`8x 多采样透明`**
* **显存回退（CUDA Sysmem Fallback）**：显存达到 **8GB 及以上** 的玩家可尝试 **「偏好不回退（防掉帧）」**，减少激战时借用系统内存造成的剧烈掉帧；显存本身较小的用户请保留回退，避免直接爆显存报错。

### 4. 帧格（运行时持续改善游戏表现）

「帧格」是本工具的核心运行时功能，开启后会在游戏运行期间持续守护帧率表现：

* **目标游戏启动时重启 DWM（Intel 显卡必开）**：
  * **如何判断是否需要**：对比游戏启动前后的任务管理器。如果游戏启动前 `dwm.exe` 占用极低，但进入游戏后其 CPU 占用异常飙升，且手动结束 DWM 后恢复正常，请开启此项。目前发现 Intel 显卡玩家较容易遇到该问题。
  * 开启后会在目标游戏启动 **约 5 秒后** 自动重启一次 DWM。DWM 会由系统立即拉起，屏幕闪烁一下属于正常现象。
* **电源计划锁定**：每 30 秒巡检一次，将电源计划锁定在指定方案，并在游戏期间防止计划内容被第三方软件篡改。
* **加速系统响应**：包含 **核心停驻（防核心停放）**、**游戏进程禁用电源节流（禁用 EcoQoS）** 与 **系统定时器 0.5ms**，降低突发调度与输入延迟。
* **前台响应加速**：将多媒体后台资源预留从 20% 降至 10%，并切换为前台优先的处理器调度策略，把 CPU 时间片倾斜给游戏。
* **降低省电延迟**：关闭网卡省电、USB 选择性暂停与 PCIe ASPM 省电，降低外设或总线休眠导致的断流、跳 Ping 与鼠标卡顿。
* **内存占用过高时**：旧版帧格的全局内存清理已经下线。需要自动或手动回收后台应用工作集时，请前往 **「进程管理」→「后台管理」→「后台内存回收」**。该功能不结束进程，可能引起换页，且不能保证一定提升帧率。

### 5. CPU 实验室（无省电计划与 AMD 双 CCD 独占调度）

#### 台式机电源计划

台式机玩家可在 CPU 实验室点击 **「导入无省电电源计划」**。计划导入后会自动激活，也可通过 **「切换到无省电电源计划」** 手动启用；配合「帧格」中的电源计划锁定效果更佳。

#### 处理器核心调度策略

* **Intel / 通用自由调度**：支持调整异类调度策略（生效策略 / 线程调度 / 短线程策略）。进程亲和性与持久规则请在 **「进程管理」** 中设置。
* **AMD 单 CCD 处理器**：可在 CPU 实验室点击 **「排除 CPU0」**，把系统中断与内核进程更集中地留在 `CPU 0`，减少对游戏主线程的干扰。
* **AMD 双 CCD 处理器（如 7900X / 7950X / 7950X3D / 9950X / 7945HX 等）**：
  * **调度原理**：通过硬约束让游戏独占一个完整 CCD，吃满该 CCD 的全部计算核心及对应三级缓存；同时通过软约束排除 `CPU 0`，将后台进程驱赶到另一个 CCD，减少跨 CCD 延迟。
  * ⚠️ **游戏模式与散热避坑**：
    * **全面战场与烽火地带（摸金）**：开启双 CCD 专属调度后，帧数与帧生成曲线的平滑度通常优于传统关核方案。
    * **黑潮爆破模式**：该模式底层调度逻辑不同，开启双 CCD 反而可能变卡，玩黑潮爆破时建议关闭双 CCD 调度。
    * **笔记本玩家**：双 CCD 满载会带来更高的发热与功耗，请确认散热能力后再开启。

## 四、进阶设置与实用特性

在左侧导航栏底部的 **「拓展插件」** 与 **「设置」** 中，还有多项实用功能：

* **拓展插件**：支持导入 `.dnfdplugin` 插件包（仓库已提供弱网优化与硬件报告等示例），可查看运行历史、恢复备份并管理逐插件授权。导入后默认禁用，必须确认权限后才能启用。
* **「不玩三角洲辣」模式**：如果你要玩其他游戏，可在 **「设置」** 中开启该模式并选择目标主进程，让帧格与进程/CPU 调度等支持自定义目标的功能转向你指定的游戏。
* **个性化与自动更新**：支持浅色 / 深色主题、自定义背景图与遮罩浓度、开机自启并最小化到托盘，以及带 SHA256 校验的在线版本更新。
* **旧版脱机模式已下线**：当前版本不再提供“关闭工具后继续零残留运行”的脱机模式。请保持工具及对应后端在需要优化时正常运行；如果从旧版本升级，请按工具提示完成遗留脱机状态恢复。

## 五、如何安全还原修改

DeltaNFD 会为支持回滚的系统写入保存原值，并尽量提供对应的还原入口：

* **常规还原**：在对应功能页点击「恢复默认」「恢复全部核心」「恢复修改前配置」或「强制清理拦截」等按钮；系统优化页可点击 **「一键恢复」**。
* **自动还原**：帧格退出后会还原临时调度与省电项；电源计划锁定会恢复开启前的计划；临时显卡伪装会依据登记在重启或登录后自动还原。
* **需要手动处理的项**：显卡伪装可在「显卡伪装」页恢复原型号；部分应用移除项（如 APPX 应用与 OneDrive）需要从 Microsoft Store 或官网重新安装。
* **意外中断**：重新打开工具后，按「未确认的后端操作」或恢复提示完成状态核对，不要在未确认原值的情况下重复应用优化。
