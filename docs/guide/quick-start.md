# 快速上手与环境整备指南

欢迎使用 **DeltaNFD**！本指南帮助你用最短时间完成《三角洲行动》的帧率优化与运行环境修复。

## 一、 安装与启动要求

1. **操作系统**：Windows 10 / Windows 11 64位系统。
2. **管理员权限**：由于涉及底层 CPU 调度（Core Parking / CPU Sets）、电源方案导入（`NoPowerSave`）以及系统服务/注册表配置，启动时请确保赋予**管理员权限**。
3. **自包含运行**：官方安装包已内置所需环境，若系统 `.NET` 环境异常，可使用内置的 **DotNetRepair** 工具一键修复。

## 二、 推荐调优三步曲

### 第一步：仪表盘（Dashboard）全局体检

打开软件后首先进入**仪表盘**，系统会自动扫描：

* 游戏安装路径（支持自动定位与搜索 `DeltaForceLocator`）
* 当前 CPU 拓扑结构（识别大小核或 AMD 双 CCD 状态）
* 磁盘与着色器缓存健康度

### 第二步：开启 CPU 帧率调度与推荐 Tweak

1. 前往 **帧率调度 (Frame)** 页面，根据你的处理器类型开启对应的核心绑定与停驻防休眠策略。
2. 前往 **系统调优 (System Optimize / TweakDb)** 页面，不确定如何勾选的新手可直接应用 **「UP主推荐 (UpRecommended)」** 预设。
3. 若网络环境存在抖动，可在 **插件中心 (Plugins)** 启用内置的 **弱网加速优化 (`WeakNetBoost`)**。

### 第三步：ACE 与运行库故障排查（按需）

* **遇到虚拟化提示或反作弊报错**：前往 **ACE 专区** 检查虚拟化（VBS）状态，并执行安全的分阶段残留清理。
* **遇到游戏闪退或缺少 DLL**：前往 **运行库修复 (Runtime)** 页面执行强力修复。

## 三、 如何安全还原所有修改？

DeltaNFD 的所有修改均由 `TweakBackupStore` 实时备份：

* **常规还原**：在对应功能页或设置页点击「恢复默认 / 还原备份」即可。
* **断电/死机保护**：即使电脑意外断电，`DeltaNFD.OfflineHelper` 也会在下次系统启动或超时后自动归还所有离线调度与电源计划控制权。
